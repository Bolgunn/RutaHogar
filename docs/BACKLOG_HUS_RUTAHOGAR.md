## Requisitos no funcionales

Los siguientes elementos deben tratarse como requisitos no funcionales, no como HUs independientes salvo decision posterior del equipo:

- seguridad basica;
- privacidad minima;
- roles y permisos;
- auditoria tecnica;
- historial inmutable;
- experiencia movil;
- disponibilidad;
- manejo seguro de errores;
- validacion de entradas.
